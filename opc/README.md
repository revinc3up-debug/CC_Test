# OPC 资产库：现在就能用的东西

这个目录是一人公司的"数字基建"。每个文件都是直接可用的工具或模板，不是建议。

## 目录

| 文件 | 是什么 | 什么时候用 |
|---|---|---|
| `margin_calc.py` | 单品利润计算器（命令行） | 每评估一个候选品，跑一次，30秒出"做/不做"判定 |
| `选品评分表.csv` | 候选品打分表（带判定标准） | 配合卖家精灵填数据，分数说话 |
| `供应商询价模板.md` | 1688 询价话术（直接复制粘贴） | 联系供应商时用，问齐关键信息、暴露不靠谱卖家 |
| `日文客服模板.md` | 日文客服回复模板（5个场景） | 开店后处理买家邮件，复制改数字即可 |
| `防灾清单卡-内容初稿.md` | 产品随附内容卡的日文初稿 | 防灾套装的核心差异化物料，打样时一起印 |
| `品牌名候选与查重清单.md` | 5个品牌名候选+查重操作步骤 | 本周定品牌名、查 J-PlatPat、委托商标申请 |
| `listing模板-日本站.md` | 日本站 listing 结构模板 | 写商品页时按格填空，再交母语译者润色 |
| `运营台账.csv` | 现金流水账模板 | 从第一笔支出开始记，每天1分钟 |
| `../cashflow_model.py` | 12个月现金流推演脚本 | 改参数跑你自己的情景 |

## 只有你本人能办的事（按优先级，本周就可以启动）

以下每件事都需要你的身份证件或资金，我没法代办，但模板和决策依据都已备好：

1. **公司核名+注册**——经营范围记得含"货物进出口、技术进出口"，注册资本认缴10–20万，找一名监事（家人即可）。线上提交后等执照期间，下面的事并行做。
2. **定品牌名**——从《品牌名候选与查重清单》里选，按文档里的步骤上 J-PlatPat 查重（免费、10分钟），定了就委托代理申请日本商标（约5–8千元，第18/20/21类）。这是全计划最长的等待项，越早越好。
3. **万里汇开户**——拿到执照当天就能办，1–2个工作日下户，零费用。
4. **企业支付宝**——执照下来就开，速卖通入驻要用。
5. **买卖家精灵会员**（标准版即可）——用它补实盘调研里标注的数据缺口：候选品核心关键词的精确月搜索量、头部listing月销量和评论数。半小时能填完《选品评分表》。
6. **注册 1688 账号并发询价**——用《供应商询价模板》联系实盘调研报告里圈出的货源方向，每个品类问3–5家。

## 数据缺口清单（等你有卖家精灵后补齐）

- 「猫 防災セット」「猫 食器台」等核心词在亚马逊日本站的精确月搜索量
- 头部竞品 listing 的月销量估算、评论数、上架时间
- 候选品类目的 BSR（销量排名）波动曲线（看季节性）
