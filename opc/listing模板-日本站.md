# 日本站 Listing 模板（按格填空 → 交母语译者润色）

日本站 listing 和美国站的写法完全不同：日本买家要的是**信息密度和严谨**，不是情绪和大词。
模板里【】部分填空，写完后整体交给日语母语译者润色（这笔钱不能省）。

---

## 标题公式（全角125字符以内，前50字符决定点击）

```
【品牌名】+ 品类核心词 + 核心规格 + 2-3个场景/特征词 + 适用对象
```

示例（高龄猫餐架）：
> NEKOMAMORI 猫 食器台 高さ調整可能 斜め口 木製 食べやすい 吐き戻し軽減 シニア猫 子猫対応

示例（防灾套装）：
> NEKOMAMORI 猫 防災セット 18点 キャリーリュック 折りたたみケージ 携帯トイレ付 防災士監修チェックリスト同梱 同行避難対応

注意：日本站标题用半角空格分隔关键词；不要塞感叹号和"最高""No.1"（违反景表法——日本广告法，无依据的最高级宣称违法）。

## 五点描述（每点一个主题，首句加【】小标题）

1. 【サイズ・仕様】尺寸规格——日本买家第一在意的就是精确尺寸，精确到毫米，附重量
2. 【こんなお悩みに】解决什么痛点——用具体场景：【例：食器が低くて吐き戻しが多い、シニア猫が前かがみの姿勢で食べづらい…】
3. 【設計のこだわり】设计细节——材质、角度数字（如15度斜口）、防滑设计，给数字不给形容词
4. 【お手入れ・安全性】清洁方式和安全性——可水洗？无异味？边角处理？
5. 【パッケージ・保証】内容物清单+售后承诺——【30日間返品保証、日本語サポート】

## 图片清单（7张，给摄影/美工的需求单）

1. 白底主图（产品占图85%，亚马逊硬规则）
2. 尺寸标注图（所有关键尺寸，毫米单位）
3. 痛点对比图（用前 vs 用后，如：低食器的弯腰进食 vs 餐架的自然姿势）
4. 场景图（日式室内环境！榻榻米/木地板，不要欧式客厅——买家一眼能看出"不是给日本人拍的"）
5. 细节特写（材质纹理、边角处理）
6. 内容物全家福（套装类必须）
7. 使用步骤/安装图

## 后台搜索关键词（500字节，不重复标题里的词）

高龄猫餐架方向：`食事台 ごはん台 フードボウル スタンド 餌台 高齢猫 介護 食べこぼし 防止 ウェットフード`
防灾套装方向：`避難 グッズ 地震 災害 備え ペット用 非常用 持ち出し袋 キャリーバッグ 折りたたみ`

## 禁词清单（景表法+薬機法）

- 最高級表現：最高、No.1、日本一、世界初（除非有第三方调查依据并标注出处）
- 效果断言：治る、防げる（医疗效果宣称）、必ず、100%
- 防灾品特别注意：可以写「備えに」「避難時に役立つ」，不能写「地震でも安全を保証」
