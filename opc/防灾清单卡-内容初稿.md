# 猫防灾清单卡：内容初稿

这张卡是防灾套装的核心差异化物料——成本几毛钱，但它把产品从"一个包"变成"一套方案"。
设计成 A5 双面卡片，塑封，随套装附赠。

**上线前必须做的两件事**：① 找日语母语者全文校对；② 找一位日本注册防灾士做"监修"并取得署名授权
（监修费通常数万日元，listing 和卡片上可标注「防災士監修」，这是评测站引用的入场券）。
内容依据环境省《人とペットの災害対策ガイドライン》的同行避难建议编写，印刷前请对照官方最新版逐项核对。

## 正面：愛猫の防災チェックリスト（爱猫防灾检查清单）

### いますぐ準備するもの（现在就要备齐的东西）

- [ ] キャットフード・飲料水（最低5日分、できれば7日分）／猫粮和饮用水（至少5天、最好7天）
- [ ] 療法食・常備薬（かかりつけ動物病院の連絡先メモも）／处方粮和常备药（附上常去动物医院的联系方式）
- [ ] 折りたたみ食器／折叠食盆 **※本セットに含まれます（本套装已含）**
- [ ] 携帯トイレ・猫砂（小分けパック）／便携猫厕所和小包装猫砂 **※本セットに含まれます**
- [ ] キャリーバッグ（拡張型）／扩展式航空背包 **※本セットに含まれます**
- [ ] 折りたたみケージ／折叠围栏 **※本セットに含まれます**
- [ ] 排泄物処理袋・ウェットティッシュ／排泄物处理袋和湿巾 **※本セットに含まれます**
- [ ] タオル・ブランケット／毛巾和毯子
- [ ] ガムテープ・油性ペン（ケージ補修や迷子札の代用に）／胶带和油性笔（修补笼子、临时写名牌）

### いますぐ確認すること（现在就要确认的事）

- [ ] 愛猫の写真をスマホと紙の両方で保管（迷子になった時のため）／猫的照片存手机+打印一份（走失时用）
- [ ] 首輪に迷子札・マイクロチップの登録情報は最新？／项圈名牌、芯片登记信息是否最新
- [ ] 最寄りの避難所はペット同行可能？（市区町村のHPで確認）／最近的避难所是否接收宠物（查市区町村官网）
- [ ] ワクチン接種証明書のコピーをセットに入れた？／疫苗接种证明复印件放进套装了吗
- [ ] キャリーバッグに猫を入れる練習をした？（月1回推奨）／让猫练习进背包了吗（建议每月1次）

## 背面：避難するとき（避难时）

1. **人の安全がいちばん。** まず自分の身を守ってから、猫の準備を。／先保证人的安全，再准备猫
2. キャリーに入れて移動。抱っこでの避難は脱走の危険！／必须装包移动，抱着走极易脱逃
3. 避難所ではルールに従い、鳴き声・におい対策を。／在避难所遵守规则，注意叫声和气味
4. はぐれてしまったら：環境省「収容動物検索」や自治体の動物保護センターへ。／走失后查环境省收容动物检索系统和当地动物保护中心

> 出典：環境省「人とペットの災害対策ガイドライン」に基づき作成
> 監修：【防災士氏名】（取得资质后填入）

## 给设计师的说明（中文）

- A5 双面、塑封、圆角；正面清单项用大号字+方框，老年用户也要能看清
- "本セットに含まれます"的项目用品牌色高亮——让用户直观看到"这套解决了清单的一半"
- 背面四条用图标+短句，不要长段文字
- 留出监修者署名位置；印环境省指引出处（不可印环境省 logo，只能文字引用出处）
